# 海鮮こねこ丼 VIDEO PORTFOLIO

GitHub Pages用の静的ポートフォリオテンプレートです。

## 使い方
1. `assets/video/wankome.mp4` を自分の短尺動画に置き換える。
2. `assets/js/app.js` の `works` 配列に作品を追加する。
3. GitHubリポジトリにアップロードして Pages を有効化する。

作品データには title / video / youtube / type / mood / style / tags / description / price / period を設定できます。

## タグ
- TYPE
- MOOD
- STYLE / TECHNIQUE

複数タグは同時選択できます。異なるグループの条件を同時に選ぶとAND条件で絞り込みます。

## 注意
GitHub Pagesの公開サイトには容量・帯域等の制限があります。動画ファイルを大量に置く場合は、短尺・低容量に圧縮するか、動画ホスティングを別にする構成を検討してください。
